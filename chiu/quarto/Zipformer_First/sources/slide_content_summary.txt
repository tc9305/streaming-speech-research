Slide 1: 研究題目與系統總覽
================================================================================
■ 研究題目：
  基於 Zipformer 之動態雙語熱詞與 Memory 注入機制於即時語音翻譯 (SimulST) 之研究

■ 研究背景與痛點：
  1. 在研討會、國際會議與課堂演講中，專有名詞、人名與專業術語容易出現 ASR 辨識錯誤與 ST 翻譯偏差。
  2. 現有即時語音翻譯系統缺乏針對特定場景動態調整詞彙庫的能力。

■ 核心解決方案：
  1. 開源底座：採用高效能串流架構 Zipformer 作為模型 Backbone。
  2. 動態偏置：結合演講簡報 (PPT) 的文字與圖像，擷取雙語熱詞對 (Source-Target Hotword Pair)。
  3. Memory 機制：建立外掛 Memory Bank 儲存歷史熱詞，並在解碼時進行注意力檢索。

■ 系統運作流程：
  簡報熱詞擷取 -> 雙語 Pair 建立 -> 動態 Memory 寫入 -> Zipformer Streaming 解碼偏置 (Contextual Biasing)


================================================================================
Slide 2: Streaming Backbone — Zipformer + Transducer
================================================================================
■ 技術選型：
  k2 / icefall 生態系之 Zipformer2 + Transducer (RNN-T 演進版)

■ 選擇 Zipformer 的核心理由：
  1. 高計算效率：採用 Multi-rate 結構（下採樣與上採樣），顯著降低記憶體佔用與運算延遲。
  2. 原生 Streaming 支援：支援低延遲串流解碼，適合即時翻譯 (SimulST) 需求。

■ 選擇 Transducer / Joiner 的理由：
  1. 具備「邊聽邊輸出」的增量解碼特性，較傳統 Seq2Seq 架構更適合即時串流場景。

■ 開源可行性：
  1. icefall 官方具備完整的 Zipformer 訓練與微調腳本，大幅降低二次開發與開源驗證的門檻。


================================================================================
Slide 3: 動態熱詞 (Dynamic Hotword) 與 Memory 注入機制
================================================================================
■ 雙語熱詞對 (Source-Target Pair) 擷取：
  從簡報投影片中自動擷取專有名詞，建立對應關係（例如：〔齊普變形器, Zipformer〕）。

■ Memory Bank 結構設計：
  將歷史投影片出現過的熱詞進行向量化 (Embedding) 並壓縮寫入外掛 Memory，避免搜尋空間無限膨脹。

■ 動態更新與 Contextual Biasing：
  1. 時間軸同步：當演講者切換 Slide 時，即時載入該頁相關熱詞。
  2. 神經網路注入：在 Transducer Joiner 或 ST Attention 層進行 Cross-Attention 檢索，動態提高熱詞的解碼機率。


================================================================================
Slide 4: Reviewer-Proof Policy 與對照組實驗設計
================================================================================
■ SimulST 解碼 Policy 選型：
  1. 採用學界公認標準的 Wait-k Policy（先接收 k 個語音 Token 後開啟翻譯）。
  2. 選型考量：自訂 Policy 易被 Reviewer 質疑延遲評測的客觀性，使用 Wait-k 能確保變因控管在「熱詞機制」本身。

■ 實驗組與對照組 (A/B Test) 設計：
  1. Baseline (對照組)：標準 Zipformer-based SimulST 模型（無熱詞注入）。
  2. Proposed (實驗組)：Zipformer-based SimulST + Dynamic Hotword Memory Injection。

■ 評測指標 (Evaluation Metrics)：
  1. 翻譯品質：BLEU score, ASR WER (Word Error Rate)。
  2. 即時延遲：Average Lagging (AL), Computation-aware Delay。
