「回答」與「翻譯」是不同任務

條件 輸入 希望模型做的事
C1 語音 回應錄音內容
C2 語音 英文逐字轉寫
C3 語音 翻譯錄音原話為繁體中文
C4 人工文字 跳過語音輸入路徑，要求翻譯

C3 中，研究者回報 system 與 user 訊息都改為翻譯指令，並要求不要回答錄音中的問題。

三個內容 × 四個條件，共 12 筆文字輸出。完整 prompt、腳本與原始執行檔待回收核對；C3 指令設定依研究者本次補充。

C1 是語音問答，C2 是轉寫，C3 是語音翻譯，C4 是人工文字對照。要翻譯疑問句，就應保留它是疑問句，而不是回答它。C3 的 system 與 user 指令皆已修改是研究者明確補充；目前沒有原始 prompt.txt 可逐字引用，也還不能檢查程式是否把提示正確傳進模型。

回到論文：四個主要模組

架構圖為研究者提供的版本；模組與兩階段訓練對照論文 v1 §2 與 Figure 2。

先看左下角的輸入語音，經 encoder 和 adaptor 到 LLM。LLM 一邊逐步生成文字，一邊將 hidden states 交給 speech decoder；decoder 產生 units，vocoder 再產生可播放的波形。右側說明兩階段訓練。此圖是資料流和訓練概念圖，並非每一步的實際計時圖。

§2.1–2.2：語音怎麼進入 LLM？

語音 XS　→　Whisper-large-v3 encoder　→　表示序列 H
　→　Speech Adaptor　→　LLM 可接收的語音表示 S

  • Encoder 抽取語音特徵；論文訓練時保持凍結。
  • Adaptor 將每 k 個相鄰 frame 串接，縮短序列。
  • 兩層線性層之間使用 ReLU，將特徵映射到 LLM 的 embedding 空間。

模型不需要先用 Whisper decoder 產生輸入逐字稿；adaptor 的輸出仍是連續向量。

論文 v1 §2.1–2.2，式 (1)–(2)。

Whisper encoder 先把輸入語音轉成有時間順序的表示 H。adaptor 為了降低序列長度，將相鄰的 k 個 frame 在特徵維度串接，不是把它們平均，也不是先辨識成文字。接著使用兩層線性層，中間為 ReLU，得到能放進 LLM 輸入空間的語音表示 S。

§2.3–2.4：文字與語音如何生成？

路徑 論文中的作用
LLM 將語音表示放進 prompt，逐步預測文字 token
Hidden states 提供每個文字生成步驟的內部表示
Speech decoder 上採樣 hidden states，經 CTC 預測離散語音 units
Vocoder 將 units 合成可播放的語音波形

文字 token 與語音 units 來自相連的生成流程；units 本身不能直接播放。

論文 v1 §2.3–2.4。

語音表示插入 prompt 中的 speech 位置，LLM 自回歸產生文字回應。對應生成步驟的 hidden states 再交給 speech decoder。decoder 以非自回歸方式預測離散語音單位，CTC 用來處理輸出對齊，最後由 vocoder 合成波形。這條路徑產生的是回應語音；不能把它等同於已能做輸入語音的即時翻譯。

§2.5：兩階段訓練

階段 訓練對象 目標
Stage 1 Speech Adaptor、LLM 從語音指令產生文字回應
Stage 2 Speech Decoder 產生對應的離散語音 units

第一階段凍結 speech encoder；第二階段凍結 encoder、adaptor 與 LLM。

§2.5 描述的是語音指令回應的訓練目標，沒有提出專門的語音翻譯訓練目標。

論文 v1 §2.5。這不表示可斷言訓練資料完全沒有翻譯例子。

第一階段讓 adaptor 與 LLM 學習從語音指令直接產生文字回應；speech decoder 此時不參與。第二階段固定前端，訓練 speech decoder 產生語音 units。這個目標提供了思考本次翻譯結果的背景，但本次實驗未拆解提示、語音表示、LLM 任務遵循等因素，無法據此證明真正原因。

§2.6：為什麼能逐段播放回答？

文字前綴產生　→　取得對應 hidden states　→　產生部分 units
units 累積到 chunk 大小 Ω　→　vocoder 合成一段語音

  • 不必等待完整文字回答結束，便可開始播放回應語音。
  • 這裡的 streaming 指輸出語音的逐段生成。

本輪未測輸入語音串流、端到端延遲或 streaming speech translation。

論文 v1 §2.6 與 Algorithm 1；本輪測試範圍見進度紀錄。

LLM 每產生更多文字 token，就會有新的 hidden states。decoder 可以從已有的前綴預測一部分 units；當累積數量達到指定 chunk size，vocoder 合成並播放一段回答語音。因此輸出端可降低開始播放的等待。論文這一段不是說模型邊聽使用者正在說的話邊做翻譯；我們也沒有測過那種任務。
